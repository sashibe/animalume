# 0007. LINE / Kakao Login 優先（Instagram 後回し）

## 状況

CLAUDE.md §8 Phase 5「友達相性（バイラル拡大）」の実装にあたり、ソーシャルログイン・友達リスト連携の対象プラットフォームを選定する必要があった。

候補：

- **LINE Login**（日本最大の連絡用 SNS）
- **Kakao Login**（韓国の必須インフラ）
- **Instagram Graph API**（日本の SNS で最強の影響力）
- **Twitter (X) Login**（既に §5.4 で認証用には組み込み済み）
- **Facebook Login**（日本では退潮、韓国でも限定的）

メインターゲット（20代後半〜30代前半の日本女性）と拡張ターゲット（韓国の同世代女性）双方への到達と、友達相性診断の実用性を踏まえた判断が必要。

## 決定

**LINE Login と Kakao Login を Phase 5 で先行実装する。Instagram 連携は Phase 6 以降の候補とする。**

詳細は CLAUDE.md §5.4 および §8 Phase 5 に記載。

## 理由

### 採用理由

#### 友達リスト連携の実用性

友達相性診断のターゲット相手は「実際に交流している人」である。プラットフォーム別に、友達関係の性質を整理：

| プラットフォーム | 友達関係の性質 | 相性診断との適合 |
|---|---|---|
| LINE | 連絡帳・実名・双方向 | ◎（最適） |
| Kakao | 連絡帳・実名・双方向 | ◎（最適） |
| Instagram | フォロー関係・片方向あり | △（弱い） |
| Twitter (X) | フォロー関係・匿名多い | ✗（不適） |

LINE / Kakao は「実際に話したことのある人」が登録されている。一方 Instagram の「フォロー」は片方向で、有名人や見知らぬ人のフォローも含まれるため、相性診断の対象としては実用性が低い。

#### API 提供状況

- **LINE Messaging API / LINE Login**: 友達リスト取得をサポート。実装事例も日本語圏で豊富
- **Kakao Friends API**: 友達リスト取得をサポート。韓国でのソーシャルアプリ開発標準
- **Instagram Graph API**: 2018 年以降、フォロー関係の取得を大幅に制限。サードパーティアプリが「フォローしている人」「フォロワー」のリストを取得することは現在ほぼ不可能。**相性診断用途では実装不能**

この API 制約だけで、Instagram は友達相性機能の対象から事実上除外される。

#### 韓国市場の戦略的重要性

CLAUDE.md §1.2 拡張ターゲットの「K-pop ファンダム、韓国の同世代女性」を取り込むには、Kakao Login は必須インフラ。韓国でのアプリ利用は事実上 Kakao アカウントが前提となる。

日本市場の LINE と並走させることで、両市場で同等の友達相性体験を提供できる。これは Animalume の地理的拡張戦略の根幹。

#### メインターゲットの利用実態

20代後半〜30代前半の日本女性の使用シーンを想定：

- 「LINE のグループでみんなに送って盛り上がる」が最も自然なバイラル経路
- 「友達と LINE でやり取りしながら『私たち相性いいんだって！』と話題化する」
- Instagram は「結果画像をストーリーズに上げる」シェア先として強いが、友達同士の双方向診断には不向き

この使用シーン分析から、LINE が友達相性の主軸、Instagram はシェア先として別軸で活用、という二層構造が最適。

### 却下した選択肢

#### Instagram 優先

- **却下理由**: API 制約により友達リスト取得不能。戦略的にも、相性診断には不適合
- **ただし**: Phase 2 のシェア体験では Instagram は最重要シェア先として位置づける。これは Login / 友達連携とは別軸の話

#### Twitter (X) Login

- **却下理由**: 既に §5.4 で認証目的では並走可能だが、友達相性診断には不適（フォロー関係が匿名・片方向）
- **役割**: 認証手段の一つとして提供を継続。ただし友達相性機能では使用しない

#### 全プラットフォーム同時実装

- **却下理由**: MVP-speed-first（CLAUDE.md §4.1）に反する。Phase 5 で LINE と Kakao の二本柱を確立してから、必要に応じて拡張する

#### Facebook Login

- **却下理由**: 日本のメインターゲット層での利用率が低い。韓国でも Kakao が圧倒的。実装コストに対してリターンが見合わない

## Instagram の役割再定義

Instagram は「友達相性の対象」ではなく、「結果のシェア先」として位置づける：

- **Phase 2 シェア体験**: Instagram ストーリーズ向けの 9:16 比率シェア画像を最優先で対応
- **OGP 画像**: Instagram のリンクプレビュー対応
- **ハッシュタグ施策**: `#Animalume` `#アニマリュム` のオーガニック流入経路として活用

これにより「Instagram でシェアして集客 → LINE で友達と相性診断 → リテンション」という二層導線が成立する。

## 再検討トリガー

以下のいずれかが満たされた時点で本 ADR の見直しを検討する：

- Instagram Graph API の友達リスト取得制限が緩和される（可能性は低い）
- メインターゲットの主要 SNS が変化する（TikTok、BeReal などへの大規模移行）
- 韓国市場以外の国への展開判断時（その国の主要 SNS に応じて再検討）
