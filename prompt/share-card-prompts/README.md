# Animalume シェアカード生成プロンプト集

各タイプ × 2言語 = 32枚のシェアカードを ChatGPT (DALL·E 3) で生成するためのプロンプト集です。

INFP（仲介者）の試作で品質確認済み：
- テキスト（YOUR TYPE / INFP / 仲介者 / キャッチコピー / Animalume / animalume.com）が正確に焼き込まれる
- キャラクターと装飾モチーフがブランド世界観を保つ
- 雑誌の表紙レベルの完成度

---

## 使い方

### Step 1: ChatGPT で画像生成

1. ChatGPT (有料プラン推奨、DALL·E 3 を使えるもの) を開く
2. 該当する `.md` ファイルを開く（例：`ja/06-INFP.md`）
3. 「---」以下のプロンプト全体をコピー
4. ChatGPT に貼り付けて送信
5. 画像が生成される

### Step 2: 画像を保存

1. 生成された画像をダウンロード
2. ファイル名は以下のルールで保存：

```
[番号][タイプコード小文字]-[ja/ko].png

例:
01intj-ja.png
01intj-ko.png
06infp-ja.png
06infp-ko.png
07enfj-ja.png
...
```

### Step 3: プロジェクトに配置

`animalume/public/share-cards/` ディレクトリを作成し、すべての画像を配置：

```
public/share-cards/
├── 01intj-ja.png
├── 01intj-ko.png
├── 02intp-ja.png
├── 02intp-ko.png
├── ...
└── 16esfp-ko.png
```

これで Phase 2（シェア体験）の実装で使える状態になります。

## 共通仕様

すべてのプロンプトに含まれる共通要素：

### 全体スタイル
- 韓国ウェブトゥーン × ファッション誌のソフトなエディトリアル
- 水彩タッチ、線画、フラットな塗り
- チャコールグレーの輪郭線
- くすみカラー、低彩度、quiet luxury

### 焼き込むテキスト
- `YOUR TYPE`（英字、上部）
- `タイプコード`（INTJ等、4文字、大きく）
- `─ タイプ名 ─`（日本語または韓国語、ヘアラインで挟む）
- `キャッチコピー`（タイプの本質を表す詩的な一文）
- `── Animalume ──`（下部、ロゴ的）
- `animalume.com`（下部、URL）

### 構図
- 上半分：テキスト
- 下半分：キャラクター + 装飾モチーフ
- 下部：水彩のにじみ（タイプのグループカラー）

## 生成のコツ

### ChatGPT で良い結果を出すために

1. **プロンプトをそのままコピペ**（編集しない）
2. 結果が気に入らない場合：
   - 「もう一度生成してください」と頼む
   - 「テキストの位置をもう少し上に」など微調整
3. テキストが文字化けした場合：
   - 「テキストを正確に再現してください」と再依頼
   - 通常2〜3回の生成で完璧なものができる

### 失敗パターンと対処

| 症状 | 対処 |
|---|---|
| アニメ調になる | 「韓国ウェブトゥーン × 雑誌の水彩エディトリアル」を強調 |
| キャラが派手な色 | 「くすみカラー、低彩度」を強調 |
| 文字化け | 「テキストは正確に」を強調、再生成 |
| 構図が縦に変 | 「1:1 正方形」を強調 |
| キャラが顔以外見えない | 「肩から上、画像下半分の中央」を強調 |

## 推奨される進め方

### ペース

- 1枚あたり生成（再生成含む）：3〜5分
- 32枚すべて：1時間半〜3時間

### おすすめの順序

1. **NF（光を編む人たち）4枚から**（INFJ, INFP, ENFJ, ENFP）
   - INFP は試作済み、感覚を掴みやすい
   - 親しみやすく、トーンが安定
2. **NT（光の探究者たち）4枚**（INTJ, INTP, ENTJ, ENTP）
   - 知的でクールなトーン
3. **SJ（光の番人たち）4枚**（ISTJ, ISFJ, ESTJ, ESFJ）
   - 安定感のあるトーン
4. **SP（光の踊り手たち）4枚**（ISTP, ISFP, ESTP, ESFP）
   - 動きのあるトーン

これで日本語版16枚完了 → 韓国語版16枚へ。

または、各グループから1枚ずつ先行生成し、4タイプの世界観バランスを確認してから残りを進める方法もあり。

## 完了後の活用

すべての画像が揃ったら、Phase 2（シェア体験）の実装で活用：

1. 結果画面で「シェアする」ボタンを押す
2. 対応するタイプの画像を取得（例: `/share-cards/06infp-ja.png`）
3. Web Share API で送信
4. ユーザーがSNSに投稿

CSS合成や画像生成処理が不要になり、シェア体験が劇的にシンプルになります。

## 確信度別バリエーションについて

シェアカードでは確信度（standard/shimmer/quiet）の表現は統一されています。
理由：

- シェアの目的は「タイプ表明」であり、確信度の細かい話は不要
- ユーザー心理：「私はINFPです」とシェアしたい
- 32枚で済む（128枚は現実的ではない）

確信度別の表現が必要な場合は、結果画面のキャラ画像（既存48枚）を別途使用してください。
